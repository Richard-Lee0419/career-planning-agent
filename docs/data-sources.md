# 数据与职业标准的来源

初次核对：2026-10-11；培训例证补核：2026-10-12。本项目分别维护职业能力标准与招聘岗位样本；新增六个试点角色属于前者。

## 原企业岗位样本

作者说明：此前竞赛公司提供上万条岗位材料，经筛选清洗后作为项目依据，重点为计算机相关方向。当前本地岗位表有9958条记录；原始到当前文件的完整清洗过程尚未在仓库复现。企业名称、提供日期和允许公开的范围仍需作者补充，仓库不包含原始Excel或本地数据库。

当前 `scripts/init_db.py` 将外部Excel导入 `jobs` 表，用于岗位浏览和统计；推荐接口使用另一张 `job_standard_profiles` 表。既有 `build_graph.py` 按15个科技相关岗位名称调用模型生成标准，没有实现招聘样本统计到标准构建的可复现管线。不能据此宣称推荐标准由9958条岗位直接统计得出。

日期缺年份、来源地址未保留和空描述等限制尚未通过本轮修补转化为完整招聘数据管线。旧样本不用于展示新增非IT领域的市场热度、薪资或需求频率。

## 公开运行示例

`data/demo_job_standards.json` 是4个手工示例，目的是使全新安装可运行。没有真实招聘频率依据，API明确标为 `demo_example`。既有未关联来源的标准标为 `legacy_unverified`；这不否定其全部内容，但表示不能追溯其形成过程。

## 非IT试点包

文件：`data/pilot_job_standards.json`。当前版本：`manual-pilot-2026-10-12-v2`。地区：中国大陆。v1历史演示与来源快照保留，不冒充本次v2结果。

| 领域 | 初级角色 | 核对依据 |
| --- | --- | --- |
| 市场与内容 | 市场助理 | 教育部网络营销与直播电商标准中的市场策划任务 |
| 市场与内容 | 内容运营 | 同上内容策划/编辑任务；多少科技实习任务例证 |
| 市场与内容 | 新媒体运营 | 同上新媒体运营任务；美图社区运营任务例证 |
| 人力资源 | 招聘助理 | 教育部人力资源管理招聘任务；美图招聘实习任务例证 |
| 人力资源 | 人事助理 | 教育部员工事务培养要求，项目选取初级支持任务 |
| 人力资源 | 培训助理 | 教育部培训管理任务；美图HRBP实习职责中的培训组织支持例证 |

这些角色是项目整理的入门任务集合，`type=manual_pilot`、`review_status=source_checked` 只表示来源已核对。没有岗位从业者评审、全国雇主抽样或推荐效果评价；每角色六项核心能力是控制演示范围的工程选择，不是官方统一六项标准。人事助理仍主要依据教学标准；培训例证只支持组织协助这一项职责，不能据此核实完整培训岗位要求。

教学标准提供培养背景，不能等同于本科专业到职业的固定映射或某雇主的录用门槛。专业与职业仍为多对多关系；本轮不实现全专业自动映射。资格复杂职业、独立法律/税费责任等不在试点内。

- [美图：社区运营实习任务页面](https://hr.meitu.com/en/jobIntern/67148428-1fc1-4e48-8d36-00bb1ee33826)：只交叉核对平台内容、活动及社群支持任务。
- [美图：招聘实习任务页面](https://hr.meitu.com/en/jobSocial/3e3010d0-840c-4c72-a4e2-134a6e75833e)：只交叉核对需求、渠道、联系和面试安排；海外方向英语条件未变成通用要求。
- [美图：HRBP实习培训支持任务](https://hr.meitu.com/en/jobIntern/15c51fca-8baa-4bd5-a891-8df4e98cceff)：2026-10-12读取职责正文，只用培训组织协助的例证，不把HRBP所有职责或出勤要求加入培训助理标准。

补核人事来源时，检索到高校及政府发布的岗位页面，但部分正文无法稳定获取，另有搜索摘要未能与读取正文对应的情况，均未补入标准包。人事助理的直接雇主证据仍待补齐；检索命中不等于已核实来源。

雇主页面没有明确发布日期，记录为 `null`，访问日期不冒充发布时间，未核实当前仍在招。没有复制招聘全文、导入这些岗位或计算样本频率；来源链接与独立任务摘要不是可任意转载原始材料的许可。

### 技能、版本与修改

包内32个技能ID是项目自己的标识，不是教育部、ESCO或O*NET编码。少量明确别名用于同一能力归一，例如“文案撰写”和“文案写作”；宽泛“Office”“HR”“数据分析”不自动替代具体业务任务。词典不调用网络或模型；更改数据包后需重启服务。

种子脚本先校验完整包，再仅添加缺失岗位；同名旧标准不覆盖，也不虚套新来源。元数据保存标准内容指纹；内容偏离原版本时，API标为 `modified_unverified`，当前内容不继续享有旧核对状态。历史路径保存生成时的匹配和来源快照，当前目录变化不会改写旧版证据。

本轮借鉴[SkillNER](https://github.com/AnasAito/SkillNER)的词典/别名/证据分离思路与[Tabiya](https://github.com/tabiya-tech/tabiya-open-dataset)的稳定ID及来源组织方式，没有复制其代码或导入国外技能数据。中国资料检索组织参考[occupation-analysis](https://github.com/flyboat403/occupation-analysis)；该仓库未见明确许可，本项目独立整理上述官方来源，没有搬用其代码或整库。
